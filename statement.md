# Problem Statement

## Problem Statement

Manually tracking student marks  on paper or in spreadsheets  is
error prone, hard to validate, and makes it difficult to answer simple
questions like "who is the class topper?" or "what is the average in
Mathematics?". Teachers need a easy, dependable tool that captures
each student's subjectwise marks, automatically calculate grades using a
consistent policy, and produces class level insights on demand  without
requiring an internet connection, or any paid software.

## Scope of the Project

The **Student's Result Management System (SRMS)** is a command line Python
application that:

- maintains a report of students and their marks across a fixed set of
  subjects (Python, Mathematics, Data Structures, English, Computer
  Networks),
- verifies every piece of user input for eg: roll numbers, names, marks before
  it is stored,
- calculates, for each student: total marks, percentage, letter grade
  (A to F), subjectwise pass/fail, and overall pass/fail,
- creates for the whole class: a rank list, the topper, the class
  average, subjectwise avg, and a pass/fail summary,

## Target Users

- **Teachers / professors** who need a fast way to record marks and
  get a class's results at the end of a term.
- **Academic administrators** who need summary statistics like pass rate,
  average, topper for reporting purposes.
- **Students**, indirectly, as the beneficiaries of an accurately and
  consistently graded marksheet.
